护甲减伤公式 —— 规格说明

本文件是公式与参数的唯一口径（不含代码）。实现分三处，改动公式请先改这里再同步，避免口径漂移：
  · docs/护甲减伤计算器.py  图形界面计算器
  · docs/ArmorCalc.java     命令行计算器
  · src/main/java/com/summy/threat/combat/ArmorDamageFormula.java   模组内实现

================================================================
一、公式（现行口径）
================================================================

1) 有效护甲
   EA = A + (A × T) / C
   · A = 护甲值（沿用原版 generic.armor，游戏内本模组允许到 500）
   · T = 护甲韧性（原版 generic.armor_toughness，本模组把上限抬到 100）
   · C = 协同除数（默认 15，越小则韧性对护甲的放大越强）
   · A = 0 时 EA = 0 —— 韧性只放大护甲，不独立提供减伤

2) 玩家侧（不截断 EA）
   减伤 = clamp(EA / (EA + K), 0, 上限)          K = 20，上限 = 85%

3) 怪物侧（对 EA 做截断）
   有效EA = min(EA, 截断点)                        截断点 = 100
   减伤  = clamp(上限 × √(有效EA / 截断点), 0, 上限)   上限 = 90%
   · EA ≥ 100 时减伤恒为 90%；怪物实际护甲可以高于 100（例如 500），
     用于配合"基于护甲值"的效果，只是减伤只认到 100

两侧都做 0% 下限保护（不会出现负减伤）。

================================================================
二、参数与配置键对照
================================================================

  参数               默认   作用与调节方向                          模组配置键（SERVER 档）
  ------------------------------------------------------------------------------------------
  协同除数 C          15    韧性权重；越小则同样的 T 提供越多 EA      damage_reduction.synergy_divisor
  玩家曲率 K          20    玩家侧 50% 减伤对应 EA = K；越大越平缓    damage_reduction.player_k
  玩家上限           85%    玩家侧天花板（EA = 113.33 即到顶）       damage_reduction.player_max
  玩家下限            0%    默认 0，仅作负值保护                     damage_reduction.player_min
  怪物上限           90%    怪物侧天花板                             damage_reduction.monster_max
  怪物有效 EA 截断    100    EA 到此值后不再参与减伤计算              damage_reduction.monster_effect_cap
  （总开关）          开    关闭后完全走原版护甲减伤                  damage_reduction.enable_custom_armor_formula

  输入范围（计算器）：护甲 A 0~500、韧性 T 0~100。
  属性上限（模组 attribute_caps 组，只抬不压、可关闭）：
    generic.armor 默认 500、generic.armor_toughness 默认 100、generic.max_health 默认 1000000。

================================================================
三、边界与单调性（按默认参数）
================================================================

  · EA = 0：玩家 0.00% / 怪物 0.00%（0% 下限保护）
  · 玩家封顶 EA = K × 上限 / (1 − 上限) = 113.33 → 85%（韧性 0 时需要护甲 113.33）
  · 怪物封顶：EA ≥ 100 → 90%
  · 两侧都单调不减、连续；T = 0 时 EA = A，公式退化为"只看护甲"
  · 玩家侧不截断：护甲 500 + 韧性 100 时 EA = 3833，减伤仍是 85%

================================================================
六、反解（给目标减伤求所需护甲）
================================================================

  A = EA / (1 + T/C)                     ← 由 EA = A(1 + T/C) 直接反解
  EA 按侧别从目标减伤反推：
    玩家：EA = K × 目标 / (1 − 目标)                （目标 ≥ 85% 无解）
    怪物：有效EA = 截断点 × (目标 / 怪物上限)²      （目标 ≥ 90% 无解）
          注意：怪物侧 EA ≥ 截断点即可达标，所以反解给的是"最低所需护甲"

  C=15 实测（韧性统一按 8）：
    玩家 60% → EA 30.00 → A = 19.57
    玩家 75% → EA 60.00 → A = 39.13
    玩家 85% → 无解（等于玩家上限）
    怪物 50% → 有效EA 30.86 → A = 20.13
    怪物 90% → 有效EA 100.00 → A = 65.22
    怪物 >90% → 无解

================================================================
七、设计提示
================================================================

  · 截断只影响"减伤计算"，不影响属性本身：怪物护甲可以堆到 500，减伤仍只算到 100，
    这样"基于护甲值"的效果（破甲、按护甲结算的伤害等）依然有意义。
  · 韧性收益（C=15）：T=12 相当于把护甲放大 ×1.8；T=100 时 ×7.67。
  · 玩家侧到顶需要 EA = 113.33：T=0 时是护甲 113.33；T=8 时护甲 73.91 就够。
  · 怪物侧到顶需要 EA ≥ 100：T=0 时是护甲 100；T=10 时护甲 60 就够。
  · 玩家下限默认 0：旧版"裸装也吃 5%"的行为已取消；需要时可把 player_min 调回正数。
