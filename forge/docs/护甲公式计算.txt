护甲减伤公式 —— 规格说明

本文件是公式与参数的唯一口径（不含代码）；可运行的计算器见同目录《护甲减伤计算器.py》。
改动公式请先改这里、再同步计算器与 Java 版，避免多处实现漂移。

================================================================
一、公式（现行口径）
================================================================

1) 有效护甲
   EA = A + (A × T) / C
   · A = 护甲值（沿用原版 generic.armor）
   · T = 护甲韧性
   · C = 协同除数（默认 15，越小则韧性对护甲的放大越强）
   · A = 0 时 EA = 0 —— 韧性只放大护甲，不独立提供减伤

2) 玩家侧减伤
   EA = 0        → 0%
   EA > 0        → clamp(EA / (EA + K), 下限, 上限)

3) 怪物侧减伤
   min(上限, 上限 × √(EA / EA上限)) —— EA ≥ EA上限 后恒定

================================================================
二、参数（默认值）
================================================================

  参数            默认值   作用与调节方向
  ------------------------------------------------------------------
  C 协同除数        15     韧性权重。C 越小，同样的 T 提供越多 EA；C 越大越接近"韧性无用"
  K 玩家曲率        20     玩家侧达到 50% 减伤时的 EA 恰好等于 K；K 越大曲线越平缓
  玩家下限          5%     仅在 EA > 0 时套用（EA ∈ (0, 1.05] 区间会被直接抬到 5%）
  玩家上限         85%     玩家侧天花板，EA ≥ 113.33 即到顶（K=20 时）
  怪物上限         80%     怪物侧天花板
  怪物 EA 上限     100     EA 到 100 即封顶（此时正好 80%）

================================================================
三、边界与单调性（按默认参数实测）
================================================================

  · EA = 0：玩家 0.00% / 怪物 0.00%
  · 玩家封顶 EA = K × 上限 / (1 − 上限) = 113.33 → 85%（T=0 时需要 A=113.33）
  · 怪物封顶 EA = 100 → 80%，之后恒定
  · 两侧都单调不减、连续；T=0 时 EA = A，公式退化为"只看护甲"

================================================================

================================================================
六、反解（给目标减伤求所需护甲）
================================================================

  A = EA / (1 + T/C)            ← 由公式 EA = A(1 + T/C) 直接反解
  EA 按侧别从目标减伤反推：
    玩家：EA = K × 目标 / (1 − 目标)（目标 ≤ 下限时按 0 处理；目标 ≥ 上限时无解）
    怪物：EA = EA上限 × (目标 / 怪物上限)²（目标 ≥ 怪物上限时无解）

  C=15、T=8 时实测：
    玩家 60% → EA 30.00 → A = 19.57
    玩家 75% → EA 60.00 → A = 39.13
    怪物 50% → EA 39.06 → A = 25.48
    怪物 80% → 无解（怪物侧上限）

================================================================
七、设计提示（当前参数下）
================================================================

  · EA 上限与韧性耦合：T 会先把 EA 抬高，所以高韧性怪更早顶到 80%。
    例：T=10 时 A=40 → EA=66.67（65.3%）；A=60 → EA=100（80%，封顶）。
  · 韧性收益（C=15）：T=12（下界合金）把 20 护甲放大到 36（+80%）；
    铁甲 T=0 只有 15。若想让"低护甲 + 高韧性"成为一条可行路线，
    需要让韧性也能来自非盔甲来源（附魔/效果/怪物属性）。
  · 玩家下限的副作用：EA>0 但极小时会被直接抬到 5%，等于"只要穿一件任意护甲就有 5%"。
    若不想要这档，把下限设为 0。
